# Visualização de Grafosg
Projeto de visualização de grafos usando HTML, CSS, Javascript e a biblioteca vis.js
[Acesse Graphs Visualization](https://graphs.denoyr.com/)

## Ferramentas
### Realização de Grafos Simples
- Utiliza das condições de Erdos-Galloi e da soma dos graus dos vértices ser par para verificar se a partir de uma lista de inteiros um grafo é realizável, e se for, utiliza um algoritmo para montar um grafo que possua esses números como sua lista de graus.

### Realização de Multigrafo
- Se uma lista não gerar nenhum grafo realizável pelas condições de Erdos-Galloi mas ainda possuir uma forma de criar um com a soma dos graus dos vértices par, então cria um multigrafo que representa essa lista. No caso do multigrafo, o grau de aleatoriedade é menor, não sendo possível gerar qualquer multigrafo possível com o algoritmo atual, mas é algo que ainda pode ser implementado.
